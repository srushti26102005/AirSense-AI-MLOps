# AirSense AI Dataset Package

Read `reports/dataset_summary.md` first.

All data in this package is synthetic and for development/testing only. Before final research model training, replace the raw data with validated historical XKDR air-quality data and matched Open-Meteo weather data, then regenerate engineered features and chronological splits.

Use the demo live snapshots and monitoring tables to develop the backend and frontend without representing the values as live environmental measurements.
